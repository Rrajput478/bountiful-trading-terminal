feat: make terminal installable on mobile via PWA

The app had a manifest and icons but no service worker, which is what Chrome
requires before offering the install prompt. Added:

- public/sw.js: precaches the app shell, serves it offline, and network-first
  for navigations. Hashed JS/CSS are discovered from the built index.html at
  install time, since on a first visit the worker is not yet controlling the
  page and those assets are fetched before any handler exists.
- API traffic is deliberately never cached: a stale quote or balance would be
  worse than a failed request, so /api goes to the network and fails loudly.
- src/components/InstallPrompt.tsx: captures beforeinstallprompt and offers a
  real install button on Android; iOS Safari gets Share -> Add to Home Screen
  instructions since it never fires that event.
- Safe-area aware positioning for notched phones, compact in landscape.

Verified against the production build:
- Service worker activates and controls the page
- CDP reports zero installability errors and zero manifest errors
- All four manifest icons return 200 image/png / svg
- Full terminal UI renders with zero page errors while offline
- /api correctly fails when offline rather than serving stale state
